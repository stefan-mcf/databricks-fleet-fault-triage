# Packaging decisions and external critique

The public showcase was scoped with a Google Antigravity research handoff and checked against the preserved project source and primary documentation. The critique informed presentation; it did not independently execute the project or verify private data. Final package validation and review are separate.

## Decisions adopted

- **A clean public repository.** Keep the private research archive intact rather than exposing its full history, account context and internal working records.
- **Lead with Databricks delivery.** Present the recorded classifier benchmark, completed jobs, MLflow tracking, Unity Catalog registration and saved Delta scoring. The assistant remains a documented failed research extension.
- **A smaller preserved executable snapshot.** The late research tree had 31 modules and roughly 33,000 source lines. The actual scoring milestone has 22 modules and 5,106 lines, without the later compiled-assistant and research-finance layers. It keeps the original CLI dependency-closed instead of replacing the real implementation with a new toy demo.
- **Provenance before polish.** Publish source identities, declared transformations and historical native-response projections alongside readable aggregate results. Hashes are not represented as proof of withheld content.
- **Progressive inspection.** Provide a short README route, deeper implementation/evidence links, and an offline synthetic rehearsal with current package checks.

The retained lightweight investigation/retrieval modules support the original synthetic rehearsal and guarded CLI. They are not the later hosted assistant implementation, and their presence supplies no assistant acceptance claim.

## Recommendations qualified or rejected

**Numerical parity is not bitwise identity.** The critique compared the observed maximum absolute difference with binary64 machine epsilon and overstated what that proves. The public claim is limited to the recorded prediction comparison across 11,910 records and its tolerance. It is not a universal ULP bound or model-file identity.

**Record both dataset notices.** The critique reduced the dataset licence to GPL alone. The current [UCI page](https://archive.ics.uci.edu/dataset/421/aps+failure+at+scania+trucks) contains both a CC BY 4.0 declaration and older GPL-v3-or-later donor wording. This package preserves that distinction and excludes data and fitted artifacts. It does not resolve the interaction or invent a new reuse grant. Original code remains reserved-rights for public inspection.

**Do not invent abstention-slice evidence.** Scored-record denominators and all 128 abstentions are explicit. Class-specific abstention statistics are not added by re-parsing the consumed test data or by treating an external description as a new project observation.

**Retain a coherent source dependency closure.** Excluding every assistant-adjacent module would break the original CLI/rehearsal or require a new implementation. The smaller historical source preserves real code while keeping the later LLM experiment in documentation. Dependency-only maintenance, including the vulnerability fix found during packaging, is separately declared; it is not relabelled as the historically executed environment.

Suggested notebooks, a website and stronger production claims were not added simply to match a presentation checklist. The actual implementation uses wheel jobs. A website is deferred, and unperformed research remains unperformed.
